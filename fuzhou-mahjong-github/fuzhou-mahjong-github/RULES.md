# 福麻大乱斗 · 完整规则说明（v10）

> 对应网页版本：**v10**（`福麻大乱斗学习模拟器-v10.html`）
> 本文按**引擎里实际跑的规则**整理，不是设想稿。凡是我觉得可能和你的本意不一致、或者规则本身有模糊地带的地方，都集中放在第 9 节，方便你逐条判断。

## 1. 基本设定

| 项目 | 设定 |
|---|---|
| 人数 | 4 人（1 真人 + 3 机器人，或 4 真人联机） |
| 牌库 | **144 张**：万 / 条 / 筒各 1-9，每种 4 张（108 张）＋ 花牌 36 张 |
| 花牌 | 8 张传统花（春、夏、秋、冬、梅、兰、竹、菊，各 1 张）＋ 东南西北中发白 各 4 张（28 张）。**福麻没有字牌**，字牌全部当花，不参与面子 |
| 起手 | 四家各 **16 张**，庄家的第 17 张由开局第一次摸牌给出 |
| 胡牌张数 | 固定 **17 张** = 5 组面子（15）＋ 1 对将（2）；杠在牌型里只算 3 张，不额外增加胡牌张数 |
| 金 | 开局翻一张数牌，**该种类 4 张全部是金**。翻出的那 1 张作为公共展示不再流通，牌局里实际可用的金是 **3 张** |
| 金的作用 | 万能牌（赖子），可以当任意一张数牌参与胡牌组型 |
| 金的限制 | **不能吃、不能碰、不能明杠、不能暗杠、不能加杠、不能点炮**。抢金抢的是开局翻出的那张**公示金**，不是谁打出的金，所以不算例外 |
| 庄家 | 首局房主坐庄；之后庄家胡牌 / 流局 → **连庄**，闲家胡牌 → 庄家下庄，**逆时针轮到下一家坐庄**（不是胡牌的人坐庄） |
| 连庄 | 每连 1 庄，胡牌时基础朵数 **+1 朵**（详见第 6 节） |
| 一圈 / 一将 | **四家各坐一次庄 = 一圈**（连庄不算新的一圈）；**四圈 = 一将**，四圈打完结算一次，重新记分 |
| 计分单位 | **片**。朵数换算成片，大牌另外加片 |

### 点数与牌的编码（技术说明，可跳过）
- 0-8 一万~九万，9-17 一条~九条，18-26 一筒~九筒
- 27-34 八张传统花，35-62 东南西北中发白（各 4 张当花）
- 金永远是数牌（0-26 之一）

## 2. 一局的开始：发牌 → 换牌 → 开金

### 2.1 发牌与补花

1. 洗牌后庄家掷 2 颗骰子（2-12 点），按点数决定从哪里开始抓牌。
2. 从庄家的下家开始，每人每次 4 张，抓 4 轮，四家各 16 张；**庄家再多拿 1 张 = 17 张**（先手牌）。
3. **补花**：手里的花牌全部亮出计分，然后从牌尾补牌；补到的如果还是花，继续补，直到补到数牌。补花过程中每张花只计 1 朵（不会重复计）。
4. 补花后张数不变：**庄家 17 张，其余三家 16 张**。

### 2.2 换牌（四家同时换，不是两人互换）

这是大乱斗最有特色的一步，规则细节如下：

| 步骤 | 规则 |
|---|---|
| 掷骰 | 庄家再掷一次 2 颗骰子，得 2-12 点（界面上有两颗骰子的摇动动画，摇完定格） |
| 重摇 | 掷出 **5 或 9** → 重摇 |
| 方向 | **3 / 7 / 11 → 给对家**；**2 / 6 / 10 → 给下家**；**4 / 8 / 12 → 给上家** |
| 公示 | 摇完会明确写出：「摇出 a + b = N 点 · 顺时针/逆时针/对家互换 · 每人给上家/下家/对家」，并单独标出**你 → 上家（谁）** |
| 出牌 | **四家各自**选一门花色（万 / 条 / 筒），从这门里挑 **3 张** 换出去；**庄家是从自己的 17 张里挑 3 张**（不是先换 16 张再摸第 17 张） |
| 传递 | 按上面的方向**环形传递**：你出的 3 张给"对家 / 下家 / 上家"，同时你收到另一家给你的 3 张 |
| 保密 | 别人只能看到"某某已选好"，**看不到别人选的是哪一门**（防止后选的人针对性避开） |
| 无效重摇 | 如果四家选的花色**完全一样**（等于谁都没换到新花色），这一轮换牌无效：**重新摇骰、重新换牌**。**不算一局结束，不涨连庄** |
| 重试次数 | 不设上限，一直重摇到换成为止（四人全同花色概率约 3.7%，连续两次已极罕见；机器人在无效后会主动换一门） |

**补充：**

- 一门不足 3 张不能选这门。
- 换牌前后手牌张数不变：庄家始终 17 张，闲家始终 16 张。换完直接开金出牌，庄家**不再额外摸牌**。
- 换牌是**按张挑**：手里两张 7 万，点一下只圈一张，可以只换其中一张。
- 换牌超时 30 秒没选，系统自动替他选"手里最多的一门"换出。

### 2.3 开金

1. 换牌结束后，从**牌尾**翻一张：如果是花，庄家计 1 朵花并继续翻，直到翻到数牌。
2. 翻到的这张数牌 → 该种类 4 张全部为金。
3. 翻出的这 1 张作为公共展示，**不进入任何人的手牌，也不再回牌墙**。

### 2.4 庄家的第一手（天胡 / 抢金窗口）

开金时，庄家手里已经是 17 张（发牌时就多拿 1 张，换牌也是从这 17 张里挑 3 张），**开金后不再摸牌，直接轮到他出牌**，此时进入两个特殊判定的窗口：

- **天胡**：庄家这一手直接成牌 → 天胡（+8 片，见 5.1 奖励表）。天胡时庄家直接胡，**没有抢金**。
- **抢金窗口**：庄家这 17 张里，除非天胡，否则必须先打掉一张多余的牌。这一手打完，**四家**都可以把**开局翻出的那张公示金**拿进手牌（16 张 + 1 张 = 17 张），能成牌就抢金（+8 片）。
- **庄家也能抢**：庄家打完这一张后手牌同样剩 16 张，与闲家条件完全一样，也能拿公示金抢金。区别只在优先级——**庄家排在最后**（见下条）。
- **抢的不是庄家打出的那张牌**：庄家打 5 万、打七条都一样，抢的永远是公示金。庄家就算把金打出来，别人也不能拿这张弃牌胡。
- **抢金优先级**：按逆时针，从庄家下家开始依次看，**庄家最后**。多家同时都能抢时，先比**叠加的大牌奖励**（清一色 / 混一色 / 金龙 / 金雀 / 对对胡 / 无花胡…加上抢金本体），**奖励大的先抢**；奖励一样大，再按逆时针顺序，先轮到谁谁胡。
- **抢金压住吃碰杠**：这一手如果有人能抢金，其他家的吃/碰/杠**一律先挂着，不能生效**——哪怕碰家手快先点了「碰」，也要等所有能抢金的人明确点「过」（或有人直接抢金胡了）。抢金的人全过，吃碰杠才按「碰/杠 > 吃」的顺序依次成立；只要有一家抢金成功，吃碰杠全部作废。
- 窗口只在这一手打牌后的响应期有效，之后不能再抢。

## 3. 摸打循环

### 3.1 摸牌

- 轮到你时从牌墙摸 1 张，摸到花立刻补花（计 1 朵，继续摸）。
- 摸到的牌在界面上单独摆在手牌最右边（绿框），打出任意一张后归位排序。

### 3.2 出牌

- 只能打自己手里的牌；打出的牌进入自己的弃牌区，全场可见。
- **金可以打出**（规则不禁止），但打出的金：别人不能吃、不能碰、不能点炮，等于一张绝对安全牌（抢金抢的是公示金，跟这张弃牌无关）。
- **金坎家**（见 4.3 金坎）手牌盖倒，只能打刚摸到的那张，不能挑牌。

### 3.3 吃

- 只能吃**上家**打出的牌。
- 必须**同一花色**、三张连续（如 2 筒 3 筒 吃 4 筒）。
- 金不能参与吃牌（手里的金永远不进吃牌组合）。
- 吃过之后副露区亮出这组顺子，然后你必须打一张牌。

### 3.4 碰

- 任何人打出的牌，你手里有 2 张相同 → 可以碰。
- 金不能被碰，也不能用金去碰（碰只认完全相同的实牌）。
- 碰完副露区亮出 3 张，然后你必须打一张牌。

### 3.5 杠（三种）

| 类型 | 条件 | 朵数 | 补充 |
|---|---|---|---|
| 明杠 | 别人打出第 4 张，你手里有 3 张 | **1 朵** | 杠后从牌尾补 1 张 |
| 暗杠 | 自己回合，手里 4 张相同 | **2 朵** | 杠后补 1 张；**金不能暗杠** |
| 加杠（补杠） | 已经碰过这张，之后摸到第 4 张 | **1 朵** | 杠后补 1 张；**金不能加杠** |

**通用限制：**

- **牌墙空了不能杠**（补不出牌），三种杠都不给按钮。
- 副露最多 5 组。**满 5 组后不能再吃/碰/杠，但仍然可以胡**（大单调就是 5 组副露 + 手里 1 张）。
- 杠后补到的牌如果自摸成牌 → 就是普通自摸（**没有额外的"杠上开花"奖励**）。
- 杠在胡牌牌型里**只算 3 张**（第 4 张是杠本身），所以杠过之后仍然按 17 张判胡。

### 3.6 抢杠

- 有人**加杠**时，如果别人的手牌 + 这张牌能凑成**有奖励的大牌**，可以抢杠胡。
- 抢杠**优先于杠**：杠不成立（副露退回"碰"），第 4 张归胡家，按**杠家点炮**结算。
- 只有大牌能抢（小胡不能抢杠），金雀 / 金坎 / 大单调(有金) 不能抢。
- 抢杠窗口里只能选"胡"或"过"，不能碰吃杠；30 秒不表态自动过。
- 抢杠本身**没有额外片数奖励**，就是按点炮那一套结算。

### 3.7 优先级与响应窗口

- 优先级：**胡 > 碰/杠 > 吃**；**抢金窗口里，抢金排在最前面**（见 2.4）。
- **胡最大，永远排在最前面**：只要有人能胡（大牌可点炮），吃碰杠一律要让路 —— 哪怕碰家手快先点了"碰"，只要胡家还没表态，碰只是"申请"，不立即生效。
  - 胡家点「胡」→ 胡成立，碰/杠/吃全部作废；
  - 胡家点「过」（故意不胡）→ 才轮到碰/杠；
  - 碰/杠也都过了 → 最后才轮到吃。
- 有人打牌后，所有能响应的家同时收到窗口；有碰/杠资格的人还没表态时，吃只是"申请"。
- 响应窗口 **30 秒**不表态自动判"过"（防掉线卡死）。
- 多家同时能胡：只算一家——**从放炮者的下家开始按座位顺序，先轮到的胡**（不是一炮多响）；抢金窗口的裁决见 2.4（先比叠加的大牌，再按逆时针）。
- **抢金窗口是特例**：能吃能碰的家即使先点了，也只是"申请"，必须等所有能抢金的家都点「过」才生效。

> 一句话：**能胡就先问胡，胡家明确不要了，才轮得到碰和吃。** 不会出现"牌都快胡了被人碰走"。

## 4. 胡牌

### 4.1 基本胡牌型

- 标准型：**5 组面子 + 1 对将**，共 17 张。
- 面子可以是顺子（吃出来的也算）或刻子（碰、杠算一组）。
- **副露是定死的**：吃/碰/杠亮出去的每一组都锁定为一个面子，不能拆回手里重新组合（这条很关键，否则会出现"借副露凑将"的假胡）。
- 金可以当任意数牌补进面子或将，但**不能改变副露已经定型的结构**。

### 4.2 自摸与点炮

| 情况 | 能否胡 |
|---|---|
| 自摸（自己摸到成牌） | 任何成牌都能胡 |
| 点炮（别人打出你胡的那张） | **只有"大牌"能点炮**；普通标准型小胡只能自摸 |
| 抢杠 | 同点炮，只有大牌能抢 |
| 抢金 | 不是点炮：抢的是**开局公示金**，**任何牌型都能抢**；可以和其他大牌叠加，唯独不能叠三金倒 |

能点炮的大牌：无花胡、有金/无金对对胡、金龙、混一色、清一色、**大单调（无金）**。

不能点炮的：普通标准型、三金倒（只能自己回合倒）、金雀（纯金雀）、金坎、大单调（剩金）。

### 4.3 特殊胡法详解

#### 三金倒（+10 片）
- 手牌里**实际有 3 张金**，不用成牌，直接倒。
- **只能自己回合倒**：起手就有 3 金（轮到自己摸牌时倒），或手里 2 金 + 自己摸到第 3 张金。
- **别人打出的牌不能倒**，不存在"点炮三金倒"。
- 三金倒**不算天胡**（它没有真的成牌）。
- 唯一例外：抢金时手里 2 金、抢进来的正好是第 3 张金 → 这 3 张金允许拆开当赖子，按**真实牌型**算（记抢金 8 + 牌型奖励，不另加三金倒 10）。

#### 天胡（+8 片）
- 庄家开金后**第一手摸牌就成牌**，且全场还没人打过牌、没人副露。
- 只有庄家能天胡；同样牌型在闲家手里只是普通自摸。
- **必须真的成牌**：3 张金散在手里只是三金倒，不算天胡；3 张金真能成刻子 + 其余成牌 → 叫**天胡金龙**（天胡 8 + 金龙 24 = 32 片）。
- 天胡和三金倒互斥：能天胡就一定按天胡算，不再给三金倒的 10 片。

#### 抢金（+8 片）
- 只在开局：庄家开金后**先打掉一张多余的牌**（庄有 17 张；天胡则直接胡，没有这一手），把**开局翻出的那张公示金**拿进手牌，16 + 1 = 17 张能成牌 → 抢金。
- **四家都能抢**：闲家手牌本来就是 16 张；庄家打完首张后同样剩 16 张，条件完全一样，也能拿公示金抢金。
- **抢的是公示金，不是庄家打出的那张牌**。庄家打 5 万、七条都能抢，只要自己拿公示金能胡。
- 需要真的成牌：公示金加进来凑不出 5 面子 + 将，就不能抢。
- 手里已有 2 金、公示金是第 3 张时，这 3 张金可以拆开当赖子，按真实牌型算。
- 自摸摸到金**不算抢金**（那只算普通自摸 / 金雀 / 三金倒 / 金龙）。
- 这一手响应期过去（有人吃碰、或下家已经出牌），就不能再抢。

**多家同时抢金，谁先抢？**
1. 先看**叠加的大牌奖励**：抢金 8 + 自己这手叠到的牌型（对对胡 / 混一色 / 纯清一色 / 金雀 / 金龙 / 无花胡），**奖励大的先抢**。
2. 奖励一样大 → 按**逆时针**，从庄家下家开始依次问，**庄家排在最后**。
3. 所以庄家不是不能抢，只是"同样大"时永远排在最后；庄家若叠了更大的牌（比如混一色），照样能压过只有空金的闲家。

**抢金是"最小的大牌"，可以和起手就成立的牌型叠加：**

| 叠加组合 | 成立条件 | 片数 |
|---|---|---|
| 抢金 + 对对胡 | 拿公示金后是碰碰胡（抢来的金一定在手里，所以只可能是有金对对胡） | 8 + 8 |
| 抢金 + 混一色 | 数牌一门、金在另一门 | 8 + 24 |
| 抢金 + 纯清一色 | 数牌一门、金也同门 | 8 + 48 |
| 抢金 + 金雀 | **加上抢来的金，手里正好 2 张金，且两张金作将** | 8 + 12 |
| 抢金 + 金龙 | **加上抢来的金，手里正好 3 张金，且三张金成刻** | 8 + 24 |
| 抢金 + 无花胡 | 胡牌时 0 花 | 8 + 8（另叠加 0 花时每金 1 片） |
| 抢金 + 三金倒 | **永远不成立** | — |

> 金雀、金龙在抢金里的条件是"**加上抢来的这张金之后**"的手牌：抢之前手里 1 金（抢后 2 金作将）或 2 金（抢后 3 金成刻）。多一张、少一张都不算。
> 抢金不能和三金倒叠加：3 张金只能拆开当赖子按真实牌型算，或者成刻算金龙。

#### 金雀（+12 片，自摸或抢金）
- **2 张金都当将**（金金作雀头），其余 15 张数牌自己组成 5 组面子。
- 只是"手里有 2 张金"不算金雀；金被拆去补面子/搭子时，按普通胡算。
- 纯金雀不能点炮；如果同时还是对对胡 / 清一色 / 混一色，按那些大牌点炮，**但不加金雀的 12 片**。
- **抢金可以叠金雀**：手里 1 金、抢进公示金后正好 2 金作将 → 抢金 8 + 金雀 12。

#### 金坎（+12 片，仅自摸）
- 条件：手里**一张金都没有**，且拿着金的前后两张（金是 8 筒 → 7 筒 + 9 筒；金是五条 → 四条 + 六条）。
- 金是 1 或 9（边张）不能做金坎（没有"坎"）。
- 自己回合宣告；如果摸牌后手里多一张，会先自动打掉一张多余的（不能打要亮的 7 筒 / 9 筒），回到卡金听形态再亮牌。
- 宣告后：亮出「7 筒 ·〔金位〕· 9 筒」，**其余手牌全部盖倒（自己也看不见）**。
- 宣告后：**不能吃、不能碰、不能杠**，只能摸牌；摸到的不是金就**原样打掉**，摸到金立刻胡。
- 金坎算 1 组副露；胡牌时必须真的摸到金，且扣掉这组坎后剩下的牌能成 4 面子 + 将。
- **金坎一旦成立，全场都不能点炮**（任何人都只能自摸），也不能再杠。

#### 大单调（+12 片；剩金 +8 片）
- **5 组副露全部亮出 + 手里只剩 1 张**，单钓这一张做将。
- 手里剩的是金 → 摸什么牌都能胡（金当将的另一半），记「大单调(有金)」+8，**只能自摸**。
- 手里剩的是数牌 → 只能钓同一张，记「大单调」+12，**可以点炮**。
- 4 组副露、手里还有 4 张（一搭 + 单张）只是普通"单钓将"，**不算**大单调。

### 4.4 胡牌时的硬校验

- 手牌张数必须正好 17 张（含副露折算后的面子），少一张多一张都不判胡。
- 胡牌判定会**认副露边界**：亮出去的每组面子固定，暗牌自己凑剩下的面子 + 将。
- 金坎必须真的摸到金那张实牌，"凭空补金"不算。

## 5. 大牌与奖励

### 5.1 奖励表

| 大牌 | 奖励 | 能否点炮 | 定义 |
|---|---|---|---|
| 天胡 | +8 | 只能自摸（且只有庄家） | 开金后庄家第一手成牌 |
| 无花胡 | +8 | 可以 | 胡牌时 0 朵花 |
| 抢金 | +8 | 不是点炮 | 开局庄家首打后，四家（含庄家）都能拿**开局公示金**加进手牌胡（与打出的牌无关）；多家同抢比叠加奖励，奖励相同按逆时针、庄家最后；可叠加其他大牌，**不能叠三金倒** |
| 有金对对胡 | +8 | 可以 | 碰碰胡，且金被当刻子/将使用 |
| 三金倒 | +10 | 只能自摸 | 手牌实有 3 张金直接倒 |
| 无金对对胡 | +12 | 可以 | 碰碰胡，金没参与牌型 |
| 金雀 | +12 | 自摸 / 抢金 | 双金作将，其余全成面子 |
| 金坎 | +12 | 只能自摸 | 用金的前后两张卡住金（如 7 筒·〔金〕·9 筒），宣告后摸到金即胡 |
| 大单调 | +12（剩金 +8） | 无金可以，剩金只能自摸 | 5 副露 + 手上 1 张单钓 |
| 金龙 | +24 | 可以 | 3 张金自成刻子，其余另凑面子 + 将 |
| 混一色 | +24 | 可以 | 一门数牌 + 花（花不算花色） |
| 纯清一色 | +48 | 可以 | 单一门数牌，全是万 / 条 / 筒 |

### 5.2 叠加与互斥

- **可叠加**：多个大牌同时成立，片数相加（如清一色 + 无金对对胡，奖励部分 = 48 + 12 = 60，再叠加基础片）。
- **抢金按"最小的大牌"参与叠加**：抢金 8 与其他牌型奖励相加，例如抢金 + 金雀 = 20、抢金 + 混一色 + 金雀 = 44、抢金 + 纯清一色 + 金雀 = 68。

**互斥 / 特殊：**

- 天胡 与 三金倒 互斥（能天胡就按天胡算）。
- 天胡金龙 = 天胡 8 + 金龙 24 = 32，不再加三金倒 10。
- 金雀在自摸、抢金时计 12；普通点炮时若同时是清/混/对对胡，按后者计，不加金雀。
- **抢金永远不叠加三金倒**：3 金只能拆赖子按真实牌型算，或成刻算金龙。
- 金龙 = 3 金成刻；3 金被拆去补面子则不算金龙（可能算三金倒）。
- 有金对对胡 / 无金对对胡按"金有没有参与牌型"二选一，不会同时出现。
- 无花胡与"0 花时每张金 +1 片"可以同时成立（见 6.3）。

## 6. 计分

### 6.1 基础朵数

```
朵数 = 花数
     + 明杠数 × 1
     + 暗杠数 × 2
     + 连庄数 × 1
     + （自摸 且 不是大牌 ? 1 : 0）
     + （不是 0 花 ? 金的数量 : 0）
```

**说明：**

- **花数**包含开局补花和过程中摸到的花。
- **金**：非 0 花时每张金算 1 朵；0 花时金不进朵，改成每张 +1 片（见 6.3）。
- **自摸 +1 朵只给"非大牌"**；大牌自摸、0 花胡都不加这 1 朵。
- **连庄**每连 1 庄 +1 朵。**流局（臭庄）计入连庄；换牌无效重摇不计**（那只是局内重摇，不是一局打完）。

### 6.2 朵数 → 片

```
片数 = 向上取整(朵数 × 2 ÷ 5)
```

- 一律 ×2（自摸、点炮都是），然后除以 5 向上取整。
- 例：10 朵 → 20 → 4 片；11 朵 → 22 → 5 片；8 朵 → 16 → 4 片。

### 6.3 0 花胡的特例

**0 朵花时：**

- 每张金**直接 +1 片**（不进基础朵）。
- 另外还有「无花胡 +8 片」。
- 例：0 花 + 3 金 + 三金倒自摸 = 基础 0 片 + 金 3 片 + 无花 8 + 三金倒 10 = **21 片/家**。

### 6.4 完整算例

| 牌型 | 计算 | 单家应付 | 赢家总收 |
|---|---|---|---|
| 5 花 + 2 金 + 普通自摸 | 5 + 1 + 2 = 8 朵 → 16 → 4 片 | 4 | 12 |
| 0 花 + 3 金 + 三金倒（自摸） | 0 + 金 3 + 无花 8 + 三金倒 10 | 21 | 63 |
| 2 花 + 天胡（庄家） | 2 朵 → 4 → 1 片 + 天胡 8 | 9 | 27 |
| 15 花 + 混一色（自摸） | 15 → 30 → 6 片 + 混一色 24 | 30 | 90 |
| 11 花 + 连庄 2 + 普通自摸 | 11 + 2 + 1 = 14 → 28 → 6 片 | 6 | 18 |
| 2 花 + 大单调（点炮） | 2 → 4 → 1 片 + 大单调 12 | 13 | 39 |
| 3 花 + 无金对对胡（点炮） | 3 → 6 → 2 片 + 对对胡 12 | 14 | 42 |

### 6.5 怎么分摊（关键：点炮也是三家一起付）

- 胡家的收入 = **单家应付 × 3**，永远收满 3 份。
- **自摸**：另外三家各付 1 份。
- **点炮**：**另外三家也各付 1 份**——放炮的人**不会**多付，不存在"点炮包三家"。
- **例外：包牌**（只对清一色 / 混一色生效，见第 7 节），会把其中几家的份额转给"喂牌的人"或放炮者。

> 这条和大多数麻将直觉不一样，先确认一下是不是你要的：现在点炮和自摸，赢家收入完全一样，区别只是谁付、以及自摸能胡小牌。

## 7. 包牌机制

### 7.1 什么时候触发

- **只对清一色 / 混一色**生效（对对胡、金雀等不包）。
- 看赢家**吃/碰/杠了几手**，以及这几手是**谁喂的**。

### 7.2 手数怎么算

- 吃、碰、明杠：各算 1 手，并记录**放牌给你的人**。
- **暗杠**：算 1 手，但**没有来源**（自己手里 4 张），所以**不进包牌链条**。
- 加杠：不重复计手数（碰的时候已经算过 1 手）。
- 包牌只认"有来源"的那几手，第 3 手、第 4 手指的就是第 3、第 4 个喂牌给你的人。

### 7.3 自摸时分摊

设单家应付 T，总额 Am = 3T。

| 手数 | 分摊 |
|---|---|
| 少于 3 手 | 三家各付 T（正常） |
| 正好 3 手 | 喂第 3 手的人付 **Am/2**，另外两家各付 **Am/4** |
| 4 手及以上，且第 3、第 4 手都是**同一个人**喂的 | 该人付 **Am/2**，另外两家各 Am/4（同「正好 3 手」） |
| 4 手及以上，且**四手都是同一个人**喂的 | 该人**全包 Am**，另外两家 0 |
| 4 手及以上，喂牌的人不同 | 喂第 4 手的人付 **Am/2**，另外两家各付 **Am/4** |

> 注意最后一行：此时喂第 3 手的人**也要付 Am/4**，不是免付。

### 7.4 点炮时分摊

| 手数 | 分摊 |
|---|---|
| 少于 3 手 | 三家各付 T（正常点炮） |
| 正好 3 手 | 放炮者付 **Am/2**，另外两家各付 **Am/4** |
| 4 手及以上，且四手都是同一人喂、且这个人就是放炮者 | 放炮者**全包 Am** |
| 4 手及以上，四手同一人喂、但不是放炮者 | 放炮者付 Am/2，喂 4 手的人付 Am/2 |
| 4 手及以上，喂牌的人不同 | **放炮者全包 Am**，另外两家 0 |

### 7.5 例子

- 你做清一色，吃了 A 两手、碰了 B 一手（共 3 手），自摸 30 片/家：总额 90，喂第 3 手的 B 付 45，A 和第三家各付 22.5。
- 同样 3 手，别人点炮：放炮者付 45，A 和第三家各付 22.5。
- 你 4 手全是 A 喂的，自摸：A 全包 90，另外两家 0。
- 你 4 手全是 A 喂的，但放炮的是 C：C 付 45，A 付 45。

> ② 换牌四家同花色只是**局内重摇**，不再给庄家涨连庄；
> ③ 去掉"连续失败 4 次就跳过换牌"，改为**一直重摇**。

按我判断的"值得改"程度排序。每条都写了：现状是什么、为什么可能是问题、我建议怎么定。

### L1. 点炮也是三家各付一份
**现状**：点炮时，放炮者付 1 份，另外两家**也各付 1 份**；胡家总收入与自摸完全一样。

**可能的疑问**：传统麻将是"点炮包三家"或"点炮者多付"，现在是"放炮者只付 1/3"。如果这是为了鼓励做大牌、避免一家被一炮打穿，那没问题；如果不是本意，需要改成"放炮者付 2 份、其余各 0.5"或"放炮者全付"。

### L2. 报听目前没有任何规则后果
**现状**：

- 不报听也能胡、也能触发包牌；
- 报听之后不能撤销，但也不影响任何判定；
- 服务端 `declareTing()` 不校验条件，只有前端按钮做了限制（吃碰 ≥3 手 + 清混形状）。
**可能的问题**：报听现在只是一个"公开宣告"，唯一的实际作用是让机器人知道你听牌了、开始防守。如果规则本意是"做清/混一色吃碰满 3 手必须报听才能胡"，那现在缺一条强制；反之如果只是提示，可以保留。

### L3. 包牌 4 手不同人时，第 3 手喂牌者仍要付 1/4
**现状**：自摸时，"喂第 4 手的人"半包，另外两家（**包括喂第 3 手的人**）各付 1/4。

**可能的疑问**：之前的设想是"第 3 手喂牌者免付"，代码里没有免。要不要让第 3 手喂牌者免付、由第 4 手喂牌者补足？

### L4. ✅ 已修（v4）：换牌无效重摇不再给庄家涨连庄
**原现状**：四家换了同一门 → 重摇，同时 `lianZhuang += 1`，等于"没打牌先涨朵"。

**v4 起**：换牌无效只是局内重摇，**不算一局打完，不涨连庄**；同时去掉"连续 4 次就跳过换牌"的安全阀，改为**一直重摇**（机器人在这轮无效后会主动换一门，人类也会调整，不会死循环；仅留 200 次极端兜底）。

### L5. 换牌超时只兜底一次，掉线后可能一直停在换牌阶段
**现状**：30 秒超时会给每个没选的人自动选一门（挑手里最多的一门，16 张牌至少有一门 ≥6 张，所以一定能选出来）。但这个兜底**只执行一次**：如果之后有人掉线重连、面板重新打开但没选，就没有第二次兜底了，其他三人会一直等在换牌界面。

**建议**：换牌阶段每次状态变化都重新计时，或者加一个"总超时"直接跳过换牌进入开金。

### L6. 金坎一旦宣告，全场都不能点炮
**现状**：`jinKanActive = true` 后，任何人打出的牌，其他三家都**不能胡、不能吃碰**，只能自摸。

**可能的疑问**：这条是"金坎者自己不能点炮"还是"全场封盘"？现在实现是后者，影响比较大（一个人宣告金坎，全场只能自摸）。如果只是想限制金坎者，需要改。

### L7. 金雀点炮不给 12 片
**现状**：金雀只在自摸时 +12；点炮时如果同时是清/混/对对胡，按后者算，金雀分不加。

**可能的疑问**：如果玩家手里双金作将、又刚好是混一色，别人点炮，他拿到的是混一色 24，没有金雀 12。是否符合预期？

### L8. 天胡金龙 = 32 片，不再加三金倒
**现状**：天胡 8 + 金龙 24 = 32；三金倒的 10 不加（三金倒与天胡互斥）。

**确认**：这是按你之前"三金倒和天胡不可能同时存在，有的话是天胡金龙"的说法实现的。

### L9. 抢杠、杠上开花都没有额外奖励
**现状**：抢杠按点炮结算（只有大牌才能抢），杠后补牌自摸按普通自摸结算，两者都没有额外片数。

**可能的疑问**：要不要给抢杠 / 杠上开花加固定奖励（比如各 +8）？

### L10. 明杠 1 朵、暗杠 2 朵，但包牌手数都只算 1 手
**现状**：计分时暗杠算 2 朵；包牌统计时暗杠只算 1 手，而且**没有来源**（不进入喂牌链条）。

**可能的疑问**：暗杠要不要算"自己喂自己"，从而影响包牌？

### L11. 打金是允许的，而且打出去没人能要
**现状**：金可以打出，但别人不能吃、碰、点炮，等于一张绝对安全牌；抢金抢的是开局公示金，不受这张弃牌影响。

**可能的疑问**：要不要禁止打金（只能留手里）？现在允许，会让"金太多用不完"的玩家有安全牌可打。

### L12. 一炮多响只算一家
**现状**：多家同时能胡时，只算从放炮者下家起先轮到的那一家，其余不胡、不结算。

**确认**：是否符合预期（很多地方规则是一炮多响、多家都收）。

### L13. 流局不结算，但庄家连庄 +1
**现状**：牌墙摸完 → 流局，无人付片，庄家连庄 +1（下局基础朵数 +1）。

**确认**：连庄累加是否包含流局（现在是包含的）。

### L14. 最后一张牌的处理
**现状**：摸到最后一张牌仍然可以打、可以自摸、可以被点炮；只有"下一次该摸牌但牌墙已空"才判流局。摸到最后一张是花、补花时墙空，也直接流局。

**确认**：这就是"摸完最后一张才算臭庄、不预留 18 张"的口径。

### L15. 换牌是四人环换，不是庄家与目标家两两换
**现状**：四家各出 3 张，按骰子方向环形传递；四家花色全相同才算无效、重摇。

**确认**：这和你最初说的"庄家与摇到的目标家交换 3 张"不一样，是后来按"四家都换"实现的。如果本意是只有庄家和目标家换，这里要改。

## 10. 一页速查

```
牌：144 张 = 万条筒 108 + 花 36（字牌全当花）
起手：闲家 16 张，庄家 17 张（发牌就多拿 1 张，换牌从 17 张里挑 3 张，开金后不再摸）
流程：发牌 → 补花 → 摇骰换牌（四家各出 3 张，同门则重摇）→ 翻金 → 庄摸打
庄：庄胡/流局连庄；闲家胡 → 逆时针下家坐庄
圈：四家各坐一次庄 = 一圈；四圈 = 一将，四圈打完结算一次

胡：17 张 = 5 面子 + 将；副露锁定；小胡只能自摸
点炮：只有大牌能点；点炮三家各付 1 份（放炮者不多付）
金：百搭，不能吃碰杠，不能点炮
抢金：开局庄家首打后，四家（含庄家）拿公示金加进手牌胡（+8），抢的不是弃牌
      多家同抢比叠加奖励，奖励相同按逆时针、庄家最后
      抢金压住吃碰杠：能抢金的家全点过，别家才能吃碰
      可叠加对对胡/清混/金雀/金龙/无花；不能叠三金倒

朵 = 花 + 明杠×1 + 暗杠×2 + 连庄 + (非大牌自摸 ? 1) + (非0花 ? 金数)
片 = ceil(朵 × 2 / 5)
0 花：金每张 +1 片，另加无花胡 8

大牌：天胡8 无花8 抢金8 有金对对8 三金倒10 无金对对12
      金雀12 金坎12 大单调12(剩金8) 金龙24 混一色24 清一色48

包牌：只清/混一色；吃碰≥3 手由喂牌者分担
      3 手：喂第3手者付一半，另两家各 1/4
      4 手同人：该人全包；4 手不同人：喂第4手者半包
```
