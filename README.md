# 福麻大乱斗学习模拟器 · v12

福州麻将「大乱斗」规则的可玩实现。含**金（百搭）**、补花、摇骰换牌、抢金、金坎、三金倒、天胡、大单调、包牌，以及**四圈一将**的圈将记账。

两种形态，同一个仓库：

| 形态 | 说明 | 部署方式 |
|---|---|---|
| **单机版** | 一个 HTML 文件，双击即玩，空座位由机器人补 | **GitHub Pages**（纯静态，免费） |
| **联机版** | Node + WebSocket，4 人开房、输 4 位房间码 | **Render**（免费额度，能跑 Node） |

> ⚠️ **GitHub Pages 只能托管静态文件，跑不了 Node 服务端。**
> 想让朋友用手机联机打，必须把服务端放到 Render / Railway / 自己的服务器；GitHub 只用来存代码。

## v12 新增：中文报牌语音

| 能力 | 说明 |
|---|---|
| **报牌** | 谁打出什么牌就念什么：「三筒」「八万」「花」。自己打的念得响一点，别人的轻一点 |
| **动作** | 碰 / 吃 / 杠 / 暗杠 / 补杠 / 听牌 / 金坎 / 胡 / 自摸 / 抢金 / 抢杠胡 / 流局，全部有人声 |
| **牌型** | 胡牌先念牌型再念胡法：「清一色！……自摸！」「金龙！……抢金！」 |
| **语音开关** | 右下角「语」按钮，独立于 🔊 音效开关，设置记在本地 |
| **零依赖** | 48 句语音用神经网络 TTS **预生成**成一整条 mp3（96KB），随程序打包；浏览器只做解码切片，不联网、不比设备语音包、没有 TTS 合成延迟 |

为什么不直接调浏览器自带的 `speechSynthesis`：那玩意儿的音色取决于手机装了什么语音包（很多安卓机没有中文包），首句还有几百毫秒合成延迟，一巡牌打完才念出上一张。预生成 + 切片是唯一能保证「打出去就出声」的做法。

> 音色是**女声（晓晓）**，念的牌名和牌面上的字完全一致。想换音色或改念法：改 `tools/make-voice.py` 顶部的 `VOICE` / `WORDS`，跑一次脚本 1 分钟出整包，索引会自动写回 `public/game.js`。

## v11 新增：音效 · 大牌特效 · 快捷表情

| 能力 | 说明 |
|---|---|
| **全程音效** | 发牌、摇骰、换牌、开金、摸牌、出牌、吃、碰、杠、听牌、金坎、胡牌，每一种动作一个声音；全部用 Web Audio **现场合成**，不加载任何音频文件（离线可用、不增加部署体积） |
| **大牌特效** | 有叠加奖励的大牌胡出来时：金光爆闪 + 旋转光芒 + 撒金 + 屏幕震动 + 牌型大字（清一色 / 混一色 / 金雀 / 对对胡…）；普通胡只有一记短闪，不喧宾夺主 |
| **快捷表情** | 右下角 😀：打快点打快点 / 救命 / 别做了求求了 / 还有谁。点一下全桌可见，气泡贴着说话人弹出，每个表情有专属音效 |
| **音效开关** | 😀 下面的 🔊 一键静音，记在本地，下次进来还是静音 |
| **首页规则** | 首页右上角「规则」：10 节折叠说明（上手 / 花与金 / 开局 / 抢金 / 吃碰杠 / 大牌表 / 算片 / 包牌 / 音效与语音 / 易踩的坑），不用翻文档 |
| **返回首页** | 房间等待界面底部「← 返回首页」，随时退房重进；房主离开自动把房主交给下一位真人 |

小提示：

- iPhone 侧面的**静音键**会同时静音网页音效，听不到先看那里。
- 大牌特效播放时，结算面板会**等特效放完再弹**；急着看牌谱，点一下屏幕就跳过。
- 表情用服务端广播（`{t:'emoji'}`），不进牌局状态，不会因为发表情刷新牌桌；同一人 0.9 秒内只能发一条。
- 音效事件由服务端下发（`state.events`），所以"碰"和"出牌"、"小胡"和"大牌"在前端分得清，不靠猜。
- 退房走的是 `{t:'leave'}`：等待阶段才会让出座位；对局中不显示这个按钮，避免把牌局弄散。
- 「请横屏」提示只在**牌桌**出现，大厅竖屏也能正常看规则、建房。

## 一、只想自己练：GitHub Pages（推荐先做这个）

仓库里的 `docs/` 就是给 Pages 用的静态站，内容是一个完整的单机版页面。

1. 把本仓库推到 GitHub（见 `DEPLOY_GITHUB.md`）。
2. 仓库页 → **Settings** → 左侧 **Pages**。
3. **Source** 选 `Deploy from a branch`；
   **Branch** 选 `main`，目录选 **`/docs`** → **Save**。
4. 等 1–2 分钟，页面顶部会出现地址：

```
https://<你的用户名>.github.io/<仓库名>/
```

5. 手机打开这个地址就能玩，也可以「添加到主屏幕」当 App 用。

**注意**

- 免费账号需要仓库是 **Public** 才能开 Pages。
- 更新游戏后，把新的单机版 HTML 覆盖 `docs/index.html` 再提交即可。
- 国内访问 `github.io` 速度一般，第一次打开可能要等几秒。

## 二、想和朋友联机：GitHub 存代码 + Render 跑服务

`render.yaml` 已经写好，Render 可以直接读。

1. 注册 [Render](https://render.com)，选 **Sign in with GitHub**。
2. 右上 **New** → **Web Service** → 选这个仓库 → **Connect**。
3. 配置一般会自动识别：
   - Runtime：`Node`
   - Build Command：`npm install`
   - Start Command：`npm start`
4. Plan 选 **Free** → **Create Web Service**。
5. 等 2–3 分钟构建完，得到：

```
https://<服务名>.onrender.com
```

手机打开这个地址 → 输入昵称 → 创建房间 → 把 4 位房间码发给朋友。

**免费实例的两个限制（正常现象）**

- 15 分钟没人访问会休眠，下一次打开需要等 **30–60 秒**冷启动。
- 每月 750 小时额度，4 个人偶尔玩完全够用。

## 三、本地运行（改代码时用）

```bash
npm install
npm start
# 打开 http://localhost:3000
# 手机与电脑同一 Wi-Fi 时，用启动日志里的局域网地址
```

跑测试：

```bash
npm test          # 22 个测试文件
npm run sim       # 200 局机器人模拟
```

单机版重新打包（需要 Python 3）：

```bash
python3 build-single.py   # 生成 福麻大乱斗学习模拟器-v<N>.html
```
